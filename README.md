# Jogo da Forca em Kotlin

Um simulador clássico do Jogo da Forca, desenvolvido para terminal, focado em lógica pura e legibilidade. Este projeto foi construído como um exercício de transição para a linguagem Kotlin, priorizando uma escrita explícita e bem estruturada.

## Funcionalidades:

* Dicionário Multitemático: Sorteio aleatório entre categorias variadas:
    * Filmes, Desportos, Animais, Comida, Cores e Jogos.
* Sistema de Vidas: O jogador começa com 10 vidas. Cada erro aproxima o fim do jogo.
* Inteligência de Input: 
    *   O jogo ignora a diferença entre maiúsculas e minúsculas.
* Sombra Dinâmica: A palavra aparece escondida por traços "-", revelando a letra correta em todas as suas posições simultaneamente quando o jogador acerta.

## Tecnologias Utilizadas:

*   Linguagem: Kotlin
*   Paradigma: Programação Funcional e Imperativa.
*   Estruturas de Dados: "MutableMap" para o dicionário e "MutableList" para a gestão dinâmica da palavra e das letras usadas.

## Como Executar:

1.  Utiliza um IDE de Kotlin.
2.  Descarrega o ficheiro "jogoForca.kt".
3.  Compila e corre o programa.
